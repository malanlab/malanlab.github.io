# Resources

This page contains useful software, datasets, tutorials, documentation, and learning materials related to computational neuroscience, neuroengineering, and biomedical signal processing.

## Software

<div class="grid">

<div class="card">
<h3>MNE-Python</h3>
<p>Python package for MEG and EEG analysis including preprocessing, source localization, connectivity, and decoding.</p>
<a href="https://mne.tools/" target="_blank">Visit →</a>
</div>

<div class="card">
<h3>FieldTrip</h3>
<p>MATLAB toolbox for EEG, MEG, invasive electrophysiology and advanced signal analysis.</p>
<a href="https://www.fieldtriptoolbox.org/" target="_blank">Visit →</a>
</div>

<div class="card">
<h3>EEGLAB</h3>
<p>Interactive MATLAB toolbox for EEG preprocessing and ICA.</p>
<a href="https://eeglab.org/" target="_blank">Visit →</a>
</div>

</div>
